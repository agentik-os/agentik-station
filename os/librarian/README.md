# Librarian OS v3.0.1 — UNIVERSAL KNOWLEDGE

Librarian OS is no longer primarily a book-analysis system.

It is the **knowledge acquisition, verification, contradiction, synthesis and memory-governance layer** of Agentik / AGK.

It can combine, when actually available:
- books and long-form authored knowledge
- live web research
- official documentation
- academic literature and bibliographic metadata
- standards and regulation
- code repositories and technical evidence
- expert and practitioner material
- community / field evidence
- authorized private/company knowledge
- multiple LLMs' latent knowledge as **unverified hypothesis generators**

The output is not “more information”. The output is a traceable knowledge graph containing sources, claims, confidence, contradictions, uncertainty, freshness and applicability.

## Core doctrine

**LLM prior → hypothesis → research → verification → synthesis → durable knowledge.**

Never:

**LLM says it → save as truth.**

The recovered Librarian FULL system, its `/book` pipeline, Bestseller discovery, evidence graphs, learning workflows, evals and Hermes installation material are preserved inside this package.
