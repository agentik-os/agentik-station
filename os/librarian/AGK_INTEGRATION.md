# AGK / Station integration

The canonical Librarian package is version 3.0.1 in Station 11.32. Its upstream v3.0.0 Universal Knowledge provenance remains unchanged; corrected profile distributions use a new immutable package version, not an overwrite of deployed bundles.

Primary research lanes include:
- `/research --deep`
- `/book --deep`, scholar/systematic/corpus/apply/compare/synthesize/critique/learning modes
- `/bestseller` discovery plus `/book --bestseller` original editorial construction
- `/web-deep --recursive`
- `/experts`, `/canonical`, `/latest`, `/papers`, `/docs`, `/github`, `/community`
- `/contrarian`, `/triangulate`, `/factcheck`, `/knowledge-gap`, `/refresh-knowledge`
- `/research-to-os` and `/handoff`

Model priors seed hypotheses only; they never silently become evidence.
Builder must consume verified Librarian handoffs rather than invent domain doctrine.
