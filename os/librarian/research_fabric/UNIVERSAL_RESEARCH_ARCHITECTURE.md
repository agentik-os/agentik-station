# Universal Research Architecture

Librarian OS v3 treats books as one source class inside a wider knowledge acquisition fabric.

## Source ladder

### Tier A — Primary / authoritative
- official documentation
- standards and regulations
- original papers and datasets
- company filings / official statements
- source code / repositories when relevant
- direct authorized documents

### Tier B — Scholarly synthesis
- systematic reviews
- meta-analyses
- peer-reviewed reviews
- academic indexes and citation graphs

### Tier C — Durable authored knowledge
- books
- textbooks
- practitioner manuals
- canonical essays

### Tier D — Current web knowledge
- technical articles
- credible expert sites
- conference material
- high-quality newsletters
- current market material

### Tier E — Community / field evidence
- GitHub issues/discussions
- forums
- Reddit and practitioner communities
- postmortems
- user reports
- case studies
- social material when useful

### Tier F — Model prior knowledge
The model's internal knowledge is NOT evidence.
It may only be used to:
1. generate hypotheses;
2. suggest vocabulary, authors, sources or missing angles;
3. propose claims to verify;
4. identify possible contradictions;
5. seed search queries.

Every model-prior claim starts `UNVERIFIED_MODEL_PRIOR`.
It can be promoted only after external or authorized-source validation.

## Universal pipeline

QUESTION
→ DOMAIN MAP
→ MODEL-PRIOR HYPOTHESES
→ SEARCH PLAN
→ MULTI-SOURCE FANOUT
→ SOURCE VERIFICATION
→ CLAIM EXTRACTION
→ CROSS-SOURCE CORROBORATION
→ CONTRADICTION MAP
→ UNCERTAINTY
→ SYNTHESIS
→ KNOWLEDGE GRAPH
→ MEMORY PROMOTION
→ HANDOFF / APPLICATION

## Research behavior

Search should be adaptive rather than fixed:
- begin broad;
- discover terminology and source classes;
- branch into specialist queries;
- follow citations and references;
- search against the current thesis;
- search specifically for failure and dissent;
- stop on saturation, not on an arbitrary number of URLs.

## Promotion rule

No consequential statement enters durable knowledge solely because:
- an LLM knew it;
- many websites repeat it;
- a book is famous;
- an expert is charismatic;
- a search engine ranked it highly.

Durable promotion requires provenance and a confidence judgement.
