# Four Owner Gates

## Gate 1 — Plan
Pass when the mission, users, non-goals, risks, success metrics and verification map are explicit.

## Gate 2 — Orchestration
Pass when the graph, Nano Director/NanoTeam, mission/thread model, capability boundaries, scopes and delegation rules are coherent.

## Gate 3 — Programming
Pass when deterministic behavior has programs/schemas/tests, integration contracts are explicit, and state transitions are reliable/idempotent where required.

## Gate 4 — Agentic
Pass when model-dependent work has clear context, tools, memory boundaries, evals, escalation/approval behavior and failure recovery.

Release is a separate gate after implementation, review, doctor, live tests, Discord readback and fresh-session acceptance.
