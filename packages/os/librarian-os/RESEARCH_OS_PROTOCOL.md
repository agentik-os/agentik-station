# Research Orchestration

## Default OS-build research graph

```text
Frame mission
  -> Topic map
  -> parallel discovery
       -> Book Deep
       -> Web Deep
       -> Expert/Operator Map
       -> Current evidence/standards
  -> source verification
  -> principle extraction
  -> contradiction analysis
  -> Bestseller editorial synthesis
  -> candidate input matrix
  -> select 15 best inputs
  -> map into OS
  -> Builder handoff
```

Parallel discovery is encouraged where sources are independent. Verification and synthesis are fan-in gates.

## Recency

Each domain is classified:

```text
stable foundation
mixed
highly time-sensitive
```

Current web research is mandatory for mixed/highly time-sensitive areas. Foundational book research remains useful even when the implementation layer moves quickly.
