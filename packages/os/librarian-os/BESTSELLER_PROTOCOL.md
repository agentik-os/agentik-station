# `--bestseller` Mode

`--bestseller` is an **editorial and pedagogy mode**.

Its question is:

> If an exceptional practitioner-author had to teach this domain clearly and usefully today, what sequence of concepts, examples, mental models and operating principles should the original work contain?

It does not mean:

- invent that a source is commercially bestselling;
- reproduce a protected book;
- stitch source passages into a derivative substitute;
- replace provenance with model intuition.

## Inputs

Bestseller synthesis happens after source discovery/verification. It uses the research packet to create original structure:

- thesis;
- conceptual progression;
- practical models;
- examples/cases expressed in original wording;
- common mistakes;
- decision frameworks;
- operating checklist;
- unresolved debates.

Builder then extracts OS-relevant principles from this editorial synthesis while preserving links back to underlying source records.
