# Librarian OS v2

Librarian is the intelligence/research OS used by Builder to create or improve domain OSs from the strongest available knowledge.

It uses several complementary approaches rather than a single `/book` path.

## Full research command

```text
/research-os --context "AGK, <mission>, <target>, <constraints>" <theme>
```

This orchestrates:

1. `/topics` — map the domain and missing questions;
2. `/book --deep` — canonical/foundational works;
3. `/web-deep` — current official/primary/practitioner internet research;
4. `/experts` — evidence-backed expert/operator map;
5. `/contrarian` when material — competing schools and failure evidence;
6. `/bestseller` — original editorial/pedagogy synthesis after source verification;
7. source verification + contradiction analysis;
8. 15 best non-redundant inputs;
9. AGK OS mapping;
10. `14_BUILDER_HANDOFF.md`.

`--bestseller` is an editorial construction mode, not an unverified sales-chart claim and never a rewrite of a protected work.

## Required output

- domain/topic map;
- real source inventory with provenance;
- source quality/diversity scoring;
- Book Deep packet;
- Web Deep packet;
- Expert/Operator map when applicable;
- original Bestseller synthesis;
- principles + contradictions;
- 15 best inputs;
- input-to-OS matrix;
- Builder handoff.
