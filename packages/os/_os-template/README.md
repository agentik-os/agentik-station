# AGK OS v2 Template

Start here for every new OS. Builder must complete every required component, use Librarian for the 15-input handoff, resolve integrations through capability contracts, bind a dedicated Nano Director Discord bot/channel, and pass Doctor + rollback/recovery + fresh-session acceptance before release.

Composio is available under `08_INTEGRATIONS/` when a capability requires managed SaaS authentication/toolkits/triggers/MCP/sandbox. It is not mandatory for OSs that do not need it.
