# Third-Party Software

Station integrates with external projects rather than relicensing them. Before distribution or production deployment, retain and review each upstream license and notices. Key integrations include:

- NousResearch Hermes Agent
- DietrichGebert Ponytail
- ComposioHQ Composio
- Tailscale
- Podman and its runtime dependencies
- Restic

The Station repository must not copy third-party credentials or imply ownership of these projects.
