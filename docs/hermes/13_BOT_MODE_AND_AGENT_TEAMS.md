# Hermes Bot Mode and Agent Teams — Station v6

Hermes profiles/Bot Mode are the canonical primitive for persistent AI coworkers.

```text
Persistent responsibility -> Hermes profile/Bot
Durable asynchronous work -> Kanban task
Temporary specialist help -> delegate_task
Persistent team -> Bot Group / profiles + shared mission graph
```

## OS mapping

```text
OS Nano Director -> persistent Hermes profile/Bot -> dedicated Discord bot identity
NanoTeam members -> persistent profiles/Bot Group members
Temporary specialists -> delegated subagents
```

Internal specialists do not receive Discord applications merely because they are agents. Promote a specialist to a dedicated public bot only when the OS contract intentionally gives it a separate persistent external identity.
