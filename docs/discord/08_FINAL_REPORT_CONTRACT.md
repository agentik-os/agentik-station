# Final Mission Report Contract

A final response is not merely "done".

Required sections when applicable:

```text
Outcome
What changed / what was delivered.

Plan result
Completed, revised, skipped or failed nodes.

Verification
Tests, evals, independent checks, live acceptance.

Artifacts
PRs, files, docs, dashboards, evidence links.

Problems encountered
Only real material problems and their resolution/state.

Remaining risk
Only unresolved risks.

Next actions
Only if follow-up is genuinely required.
```

The final card must be understandable without reading the hidden tool trace. Detailed logs remain accessible through Evidence/Diagnostics.
