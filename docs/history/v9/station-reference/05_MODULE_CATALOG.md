# Station Module Catalog

## System modules

| Module | Function | Runtime |
|---|---|---|
| Station Control | desired-state compiler, registry, bindings | deterministic service + AGK |
| Station Policy | context injection + pre-tool guardrails | Hermes hooks/plugin + Linux boundaries |
| Station Maintainer OS | upstream diff, drift, improvement, promotion missions | Hermes Bot/Profile + Kanban |
| Discord Bootstrap OS | roles/categories/channels/permissions/bindings | Hermes profile + Discord gateway |
| Builder OS | creates/upgrades OS packages | Hermes profile/team + programs |
| Librarian OS | sourced domain research → Builder handoff | Hermes profile/team |
| DevOps OS | engineering/deploy/recovery | Hermes team + Ponytail |
| Evidence | event/eval/release receipts | deterministic store/hooks |
| Backup/Recovery | state backup, restore, DR | host tools + OS recovery programs |

## Workload modules

- private personal OSs;
- business OSs;
- project-specific OSs;
- client OSs on client Nodes;
- marketplace OS packages.

System modules may be shared as **code/packages** across Nodes. Their secrets/state are never globally shared.
