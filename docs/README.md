# Agentik Station Documentation

Current documentation is organized by responsibility:

- `architecture/` — Linux foundation, Zones, Projects, local/remote placement, Fleet and repo bootstrap.
- `foundations/` — vision, principles, canonical terminology and decisions.
- `hermes/` — Hermes-first runtime mapping and configuration strategy.
- `hermes-updates/` — upstream watch, canary, promotion and rollback.
- `os/` — canonical Operative System v2 contract and examples.
- `builder/` — Builder OS compilation/release protocol.
- `librarian/` — multi-source intelligence and Builder handoff.
- `engineering/` — Engineering Constitution, Ponytail, verification, Gauntlet, worktrees and harness.
- `orchestration/` — capability lanes, evidence-before-claims and executor-neutral execution.
- `discord/` — dedicated OS bot UX, plan/progress cards and Components V2.
- `integrations/` — Composio, MCP, GitHub/Linear/Notion and capability bindings.
- `security/` — boundaries and isolation.
- `operations/` — logs, evidence, drift and operational readiness.
- `distribution/` — packaging and marketplace concerns.
- `diagrams/` — Mermaid architecture diagrams.
- `history/` — historical, non-canonical snapshots only.

Start with [`../ARCHITECTURE.md`](../ARCHITECTURE.md), not with history.
