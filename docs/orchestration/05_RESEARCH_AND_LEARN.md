# Research and Learn

Research activates Librarian Intelligence rather than ad-hoc browsing.

## Research graph

```text
question
→ topic map
→ freshness requirement
→ source-quality policy
→ book/canonical lane
→ web/current lane
→ expert/operator lane
→ primary/official sources when available
→ contradiction/failure lane
→ source verification
→ synthesis
→ confidence / gaps
→ actionable inputs
```

## Freshness classes

- `live`: current availability/status/market/news; must be checked at execution time.
- `recent`: changing technology/practice; current sources preferred and dates recorded.
- `stable`: foundational domain knowledge; canonical sources can dominate.
- `historical`: primary/historical evidence preferred where appropriate.

## Source-quality boundaries

A claim must never silently upgrade from weak evidence to strong fact. The research packet tags source type and quality, and final synthesis keeps material disagreements visible.

## Learning

Learning candidates are distilled after verification. The learning loop may propose memories/Skills, but governance controls promotion into stable OS behavior.
