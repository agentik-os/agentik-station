# Marketplace Model

An OS should not be a ZIP of prompts.

It is a versioned installable operational package.

## Categories

```text
Universal OS
├── DevOps
├── Knowledge
├── Research
└── Content

Industry OS
├── Search Funds
├── Dental
├── Legal
└── ...

Private Organization OS
├── Example Client private
├── Example Client B private
└── Client-specific
```

## Installable asset

An OS package can include:
- Profile Distribution
- NanoTeam roles
- Skills
- Capability requirements
- Memory schema
- Data schema
- Workflows
- Automations
- Evaluations
- Evidence
- Permissions
- Doctor
- UI metadata

## Marketplace promise

```text
Buy / Install
→ connect capabilities
→ connect Discord
→ Nano Director available
→ organization can operate
```
