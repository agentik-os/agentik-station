# Commercial Deployment Models

## 1. Managed Node

Agentik operates infrastructure.

Pros:
- simple onboarding
- easy support
- centralized management

Cons:
- higher trust/compliance burden
- must isolate carefully

## 2. Client-Owned Node

Client owns:
- VPS
- GitHub
- Discord
- Linear
- Notion
- credentials

Agentik installs and manages software.

Best default for serious enterprise clients.

## 3. Hybrid

Client owns state/data/integrations.

Agentik owns:
- release control
- licensing
- OS updates
- verified skill packs
- management plane

Potential long-term enterprise model.
