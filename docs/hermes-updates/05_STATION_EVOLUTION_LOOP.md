# Station Evolution Loop

```text
OBSERVE
Hermes upstream + Station failures + evidence
    ↓
UNDERSTAND
release/docs/code capability diff
    ↓
SIMPLIFY
Hermes-native-first + Ponytail
    ↓
PLAN
Builder/DevOps Loop-Graph
    ↓
LAB IMPLEMENT
isolated candidate
    ↓
VERIFY
Gauntlet + Doctor + fresh session + recovery
    ↓
PROMOTE
Station candidate/stable release
    ↓
LEARN
skill/memory candidate with governance
```

A self-improving agent can propose Station improvements. It cannot silently change hard boundaries, client isolation, release gates or stable update policy.
