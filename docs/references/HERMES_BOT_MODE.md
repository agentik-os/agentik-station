# Hermes Bot Mode Reference

Canonical documentation:

- https://hermes-agent.nousresearch.com/docs/user-guide/bot-mode

- https://hermes-agent.nousresearch.com/docs/user-guide/features/kanban

Agentik interpretation:

- Bot Mode = persistent coworker primitive.
- Profiles = persistent state/config/identity primitive, not customer host isolation.
- Bot Groups = persistent team collaboration primitive.
- Kanban = durable work primitive.
- `delegate_task` = temporary specialist primitive.
- Discord is a human organization surface compiled from OS manifests.
