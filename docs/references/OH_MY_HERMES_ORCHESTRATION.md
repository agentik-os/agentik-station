# Oh My Hermes — Orchestration Reference

Station may use OMH as an optional interop layer for prepared coding handoffs and observed executor status. The architectural value used by Station is the explicit separation between planning, observed running state, executor-reported completion and verified evidence.

Canonical Station rule: adopt the evidence semantics; do not make OMH a mandatory source of truth or capability authority.
