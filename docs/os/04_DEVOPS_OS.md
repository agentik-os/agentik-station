## Ponytail is canonical

Install on the Node when DevOps/Builder OS is enabled:

```bash
hermes plugins install DietrichGebert/ponytail --enable
```

Restart Hermes, verify plugin, and pin revision in `agentik.lock`.

Mapping:

```text
DevOps Director → full
Architect       → full
Engineer        → full
QA              → review
Security        → audit
Reviewer        → review + debt
SRE             → review where code changes
```

```text

├── #devops        → devops-director / engineering board
├── #qa            → QA surface
├── #deployments   → deployment events / approvals
```

The Bootstrap Director creates/adopts these surfaces and binds them to runtime teams.


## Executor status truth

The DevOps OS never collapses these states:

```text
Plan • not run
Code • running
Code • reported done
Test • verified
Ship • read back
Mission • accepted
```

The implementation owner may report completion, but the verifier/CI/readback gates own stronger claims.

## Optional OMH interop

OMH may be enabled as an optional prepared-handoff/observed-executor adapter for coding workflows. DevOps OS remains executor-neutral and Station evidence remains canonical. OMH is never required for the OS to function.
