# Journal OS, Decision OS and Today OS

These are important parts of Operator's Life / Business system.

## Journal OS

Structure:

```text
Journal Nano Director
├── Capture Agent
├── Reflection Agent
├── Pattern Agent
├── Memory Curator
├── Librarian
└── Reviewer
```

Flow:

```text
text / voice
→ transcription if needed
→ capture facts
→ reflection
→ detect people/projects/decisions
→ pattern extraction
→ memory candidates
→ structured JournalEntry
→ Notion / Agentik Data
```

Potential JournalEntry dimensions:
- business
- money
- relationships
- energy
- habits
- learning
- wins
- failures
- decisions
- open loops

## Decision OS

```text
question

```

NanoTeam:

```text
Decision Director
```

Decisions should be revisited against outcomes.

## Today OS

Today OS composes signals from:
- Business OS
- Life OS
- calendar
- open missions
- habits
- relationships
- decisions
- previous journal

Output:

```text
North Star
MIT
Business
Relationship
Body
Content
Decision
Avoid
```

Goal:
one clear daily execution surface rather than dozens of competing dashboards.
