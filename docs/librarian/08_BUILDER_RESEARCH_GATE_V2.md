# Builder Research Gate v2

Builder may not start full OS construction until Librarian produces:

- mission/topic map;
- Book Deep packet;
- Web Deep packet;
- Expert/Operator map when the field has identifiable practitioners;
- Bestseller editorial synthesis;
- source verification report;
- contradiction/failure analysis;
- 15 best inputs;
- input-to-OS matrix;
- `14_BUILDER_HANDOFF.md`.

Exception: a source lane may be marked not-applicable only with an explicit reason.

## Update builds

When improving an existing OS, Librarian additionally searches:

- what has changed since the OS source basis was released;
- new standards/tools/research;
- evidence that invalidates an existing assumption;
- better operator patterns;
- new failure reports.

Research refresh creates an upgrade proposal; it does not silently mutate a stable OS.
