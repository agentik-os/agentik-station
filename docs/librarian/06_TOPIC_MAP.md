# Topic / Problem Map

Before selecting sources, Librarian creates a map of what must be understood.

Suggested lanes:

```text
fundamentals
operating practice
systems/process
data/measurement
human factors
failure modes
security/risk
regulation/standards
current technology
emerging approaches
contrarian schools
```

The map prevents research from over-indexing on the first vocabulary the user or model supplied. It is revised as new source clusters reveal missing topics.
