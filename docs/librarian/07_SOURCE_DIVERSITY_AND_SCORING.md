# Source Diversity and Scoring v2

Score 0–5 with rationale:

- mission relevance ×3;
- authority/first-hand expertise ×2;
- evidence strength ×2;
- originality/foundational value ×1;
- practical transferability ×2;
- independence from other selected sources ×1;
- recency fitness ×1 when relevant;
- implementation specificity ×1;
- contradiction value ×1 when it tests consensus.

## Diversity gate

For a domain where all lanes exist, the final packet should not consist entirely of books, entirely of web posts, or entirely of one school/person. The Director must document why the selected mix is appropriate.

Numerical score never overrides obvious source quality or conflict-of-interest concerns.
