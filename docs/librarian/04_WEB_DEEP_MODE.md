# `/web-deep` Mode

The web lane finds current high-signal knowledge beyond books.

## Preferred source classes

1. official standards and documentation;
2. primary research and papers;
3. original technical/business publications from recognized practitioners;
4. conference talks and interviews with direct domain experts;
5. case studies and postmortems with concrete evidence;
6. reputable repositories / implementation references for technical domains;
7. high-quality community discussion only when experiential signal is material, clearly labeled as such.

## Search strategy

Generate multiple query families rather than one broad query:

- foundational terms;
- current best practices;
- failure modes;
- benchmarks/evidence;
- operator playbooks;
- opposing views;
- standards/regulation;
- leading people/teams;
- recent changes.

Every factual/current claim records source date when available and a verification status.
