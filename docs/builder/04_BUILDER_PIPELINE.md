# Builder OS v2 Pipeline

```text
OS request
 -> normalize outcome + mission types
 -> Librarian /book --deep
 -> select 15 inputs
 -> 14_BUILDER_HANDOFF
 -> contract matrix v2
 -> data/schema + views design
 -> Nano Director + NanoTeam topology
 -> skill graph + deterministic programs
 -> capability contract
 -> adapter compilation (Hermes/MCP/Composio/API)
 -> identity/auth/connected-account policy
 -> workflow + mission/Loop-Graph design
 -> automation/trigger design (disabled by default)
 -> eval + evidence design
 -> Discord dedicated bot/channel/commands design
 -> Doctor/update/migrations/rollback/recovery
 -> RED tests
 -> implementation
 -> Ponytail + Engineering Harness when code exists
 -> independent verification + Gauntlet
 -> candidate install
 -> account/tool bindings in the correct trust zone
 -> Discord readback
 -> fresh-session acceptance
 -> enable approved automations/triggers
 -> release
```

No OS is released because “the agent answered correctly once”. It is released when the complete installed organization passes its contract against a fresh deployed context and recoverability is proven.
