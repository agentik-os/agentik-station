# Mandatory Librarian Protocol v2

No production OS is built from model intuition alone.

## Canonical Builder request

```text
/research-os --context "AGK, <mission>, <target user>, <constraints>" <domain theme>
```

The research graph runs multiple lanes:

1. Topic/Problem Map.
2. Book Deep on canonical/foundational works.
3. Web Deep on current official/primary/practitioner sources.
4. Expert/Operator Map when applicable.
5. Contrarian/failure research when material.
6. Bestseller editorial/pedagogy synthesis from verified source principles.
7. Verification, triangulation and contradiction analysis.
8. 15 best inputs.
9. Input-to-OS mapping.
10. `14_BUILDER_HANDOFF.md`.

`/book --deep` remains mandatory but is no longer the only research lane. `--bestseller` means original editorial construction, not a commercial ranking claim and not a rewrite of protected works.

## Research gate

Builder cannot mark `RESEARCHED` unless mandatory lanes are complete or explicitly marked not-applicable with rationale, current claims are verified where recency matters, 15 strong inputs are present (or a documented domain limitation exists), and every selected input maps to a concrete OS design decision.
