# Operator toolchain

Pinned, user-local Python 3.14.7, a Python 3.13.15 AI compatibility runtime, Node.js, npm, GitHub CLI, Vercel CLI, Codex CLI and Composio CLI for the `agk-station` operator account.

Installation is not authentication. Run `station deps toolchain-check`, then enroll only the accounts and scopes required by the owning Zone or Project.
