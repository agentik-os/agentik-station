# Source packs

Source packs preserve provenance. They are **not editable canonical runtime source** and never override current contracts.

- `AGK_Builder_Librarian_OS_COMPLETE_2026-09-03.zip` is the original Builder/Librarian input pack supplied during Station design.
- Canonical active Builder and Librarian source is under `packages/os/`.
- Historical Station snapshots are under `docs/history/`.

Keeping source inputs as archives prevents four editable copies from drifting.
